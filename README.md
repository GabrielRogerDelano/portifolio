# Portfólio — Gabriel Roger

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript, pronto para publicação no GitHub Pages.

## 🚀 Como usar

1. Crie um repositório no GitHub.
2. Coloque `index.html`, `style.css` e `script.js` na raiz.
3. Edite os links do GitHub, LinkedIn e e-mail no `index.html`.
4. Faça o push para o repositório.
5. No GitHub, abra **Settings → Pages**.
6. Em **Build and deployment**, selecione **Deploy from a branch**.
7. Escolha a branch `main` e a pasta `/ (root)`.
8. Salve e aguarde a publicação.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## ✏️ Personalização

Substitua os links `https://github.com/` pelos links dos seus repositórios e altere `seuemail@email.com` pelo seu e-mail.
